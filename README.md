# Desaf-o-de-dataScience
# 🧾 Informe Final – Análisis Comparativo de Tiendas

## 📖 Introducción

Este proyecto tiene como objetivo analizar el desempeño de **cuatro tiendas** con el fin de recomendar al **Sr. Juan** cuál representa la mejor oportunidad de venta.  

Para lograrlo, se realizó un **análisis exploratorio de datos (EDA)** sobre la información disponible de cada tienda, considerando los siguientes indicadores clave:

- 💰 Ingresos totales  
- 🛍️ Categorías de productos más y menos vendidas  
- ⭐ Calificaciones promedio de los clientes  
- 📦 Productos más vendidos y menos vendidos  
- 🚚 Costo promedio de envío  

A través de **visualizaciones gráficas** generadas con Python y **Matplotlib**, se buscó identificar qué tienda combina mejor **rentabilidad**, **satisfacción del cliente** y **eficiencia logística**.

---

## ⚙️ Estructura del Proyecto

El proyecto fue desarrollado en **Google Colab** utilizando **Python** y bibliotecas de análisis y visualización de datos.  

### Archivos principales:
- `tienda1.csv`, `tienda2.csv`, `tienda3.csv`, `tienda4.csv`: Datos de cada tienda.  
- `analisis_tiendas.ipynb`: Notebook principal con todos los pasos del análisis.  
- `README.md`: Documento explicativo del proyecto (este archivo).  

### Estructura del análisis:
1. **Cálculo de ingresos totales** por tienda.  
2. **Conteo de productos vendidos por categoría.**  
3. **Cálculo de calificaciones promedio** de los clientes.  
4. **Identificación de productos más y menos vendidos.**  
5. **Cálculo del costo de envío promedio.**  
6. **Generación de visualizaciones** (barras, circular, dispersión, etc.).  
7. *(Opcional)* **Análisis geográfico** de ventas (latitud y longitud).
